## What’s new

- Review GitHub pull requests from the Context panel with a searchable inbox, diffs, checks, review conversations, and repository-aware actions.
- Add images to prompts and queued follow-ups, then see stable thumbnails and full-size previews throughout the conversation.
- Answer permission requests, questions, and plan approvals inline without losing the surrounding chat context.
- Navigate long histories and interactive Apps more smoothly, with steadier composer sizing, bounded App rendering, and more reliable restored Markdown.

## Updating from 1.1.4

DROIDEX 1.1.5 keeps the existing application identity, user-data location, session store, settings, workspaces, and raw Factory session history unchanged. The native updater waits for confirmation before restarting when a primary or child session is active.

Use **DROIDEX → Check for Updates…** or the blue update button beside Settings. The macOS artifacts are ad-hoc signed, so a manual DMG install may require approval in **System Settings → Privacy & Security** on first launch.
