## What’s new

- Keep long conversations responsive with bounded renderer memory, paged transcript restore, offscreen rendering, and automatic recovery from renderer memory exits.
- Use the refreshed composer and model picker consistently across chat, Mission Control, and browser focus workflows.
- Organize conversations with pin, archive, rename, copy, export, folder grouping, unread filtering, and stable worktree-aware history.
- Personalize DROIDEX with custom themes, app icon choices, searchable Settings, and configurable finish notifications.
- Manage GitHub, MCP servers, worktrees, and repository actions with clearer setup, status, and recovery states.

## Updating from 1.1.0

DROIDEX 1.1.1 upgrades the local session index in place while preserving existing chats, child sessions, settings, workspaces, and raw Factory session history. Quit DROIDEX before installing, then use **Check for Updates…** or download the DMG that matches your Mac.

The macOS artifacts are ad-hoc signed. A manual DMG install may require approval in **System Settings → Privacy & Security** on first launch.
