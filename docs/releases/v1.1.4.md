## What’s fixed

- Interactive Apps no longer animate large iframe height changes through the whole chat, eliminating the full-window blink during first render.
- Invalid generated JavaScript now shows a compact recovery message instead of an empty oversized canvas, and failed Apps can no longer resize the conversation afterward.
- Automatic update checks run independently of Droid CLI startup and refresh every four hours, so a discovered update appears beside Settings without a manual check.
- Installing an update relaunches DROIDEX through the native updater. If a primary or child session is running, DROIDEX asks before restarting; choosing to wait resumes the approved update on the next launch.

## Updating from 1.1.3

DROIDEX 1.1.4 keeps the existing session store and user-data location unchanged. Existing chats, child sessions, settings, workspaces, and raw Factory session history remain in place.

The macOS artifacts are ad-hoc signed. A manual DMG install may require approval in **System Settings → Privacy & Security** on first launch.
