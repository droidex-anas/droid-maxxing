## What’s new

- Schedule one-time or recurring automations that run through the sidecar with isolated worktrees, explicit permissions, review proposals, durable run history, and recovery after restarts.
- See activity, pull requests, and workspaces directly in the sidebar, then customize which sections appear and move between active work without losing session context.
- Review changes through a redesigned Context panel with clearer repository controls, focused pull request details, and more consistent diff and worktree actions.
- Paste and attach files beyond images, including documents and other local assets, while keeping queued prompts and conversation previews stable.
- Follow tool activity and model reasoning effort more clearly through dedicated controls, transcript rows, and per-model effort indicators.
- Update bundled PDF, diagram, YAML, and URL-parsing dependencies to resolve newly disclosed security issues.
- Keep large conversations and busy multi-session workflows responsive with narrower rendering updates, bounded activity feeds, and stronger stale-session isolation.

## Updating from 1.1.6

DROIDEX 1.2.0 keeps the existing application identity, Sparkle signing key,
architecture-specific update feeds, user-data location, session store, settings,
workspaces, and raw Factory session history unchanged. Automations use a new
independent store and do not rewrite existing session data.

Update checks may run in the background, but DROIDEX does not download or
install updates automatically. Use **DROIDEX → Check for Updates…** or the blue
update button beside Settings, then approve the update and relaunch. The native
updater waits for the app and sidecar to settle before installing.

The macOS artifacts are ad-hoc signed, so a manual DMG install may require
approval in **System Settings → Privacy & Security** on first launch.
