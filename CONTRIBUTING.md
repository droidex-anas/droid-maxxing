# Contributing to DROIDEX

Thanks for your interest in improving DROIDEX. This is a proprietary
source-available project, not an open-source project. A public fork may be used
only to prepare and submit contributions to the official DROIDEX repository.

## Before writing code

Open an issue describing the proposed change and wait for maintainer approval.
Only maintainers define roadmap decisions, acceptance criteria, and merge
requirements. Approval to investigate or implement a change does not guarantee
that it will be merged.

## Submitting a contribution

1. Create a focused branch in your fork.
2. Follow the repository's engineering instructions and add relevant tests.
3. Run the validation appropriate to the files changed.
4. Open a pull request using the repository template.
5. Read and explicitly accept the [Contributor Copyright Assignment
   Agreement](CLA.md) by checking the agreement box and entering your full legal
   name in the pull request.

A pull request cannot be accepted without that acknowledgement. The project
owner may request a separately signed copy for a substantial contribution.

Do not submit a contribution if you do not accept the agreement or lack the
authority to accept it, including when an employer or client owns your work.
